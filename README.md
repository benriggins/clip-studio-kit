# Clip Studio: edit videos with Claude Code + ChatGPT

Turn your raw videos (one recording or many takes) into finished **Instagram Reels, YouTube Shorts, LinkedIn
videos and full YouTube edits**. You get clean cuts, captions on every line, and animated explainers on your own
brand. Free tools only; your videos never leave your computer.

## Install (2 minutes of your time)
1. Open **Claude Code** (desktop app or terminal).
2. Paste this and press Enter:

```
Install Clip Studio from https://github.com/benriggins/clip-studio-kit and set me up. Clone it into a folder called "Clip Studio" in my home folder, then follow its CLAUDE.md step by step.
```

Claude Code downloads everything it needs, asks you a few questions about your brand, and walks you through
setting up your ChatGPT Project (ChatGPT Plus required).
